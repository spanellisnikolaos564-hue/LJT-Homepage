# LJT-Homepage

Personal academic homepage of Junteng Liu, first-year PhD candidate at the HKUST NLP Group.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (forked and customized). The site is built and deployed to GitHub Pages by the workflow in `.github/workflows/jekyll.yml`.

## Site structure

- `_pages/about.md` - about page: personal details, education, research experience, publications, honors, and contact information
- `_pages/publications.html` - publications listing page
- `_publications/` - one Markdown file per publication
- `_config.yml` - site-wide configuration and author profile
- `_data/navigation.yml` - header navigation (About, Publications)
